# Projeto Agendamento PW

Este projeto é uma aplicação web simples para **agendamento de horários**, com foco em praticidade para o cliente e para o estabelecimento.

## Como funciona

1. O usuário preenche nome, telefone e data/hora desejada no formulário.
2. Os dados são enviados para uma API (MockAPI) para registro do agendamento.
3. Após o envio com sucesso, a interface exibe um botão para iniciar conversa no WhatsApp com uma mensagem pré-preenchida para confirmação.

## Tecnologias utilizadas

- **HTML5** para estrutura da interface
- **CSS3** e **Bootstrap 5** para estilização
- **JavaScript (Vanilla)** para lógica do front-end
- **Node.js + Express** para servir a aplicação localmente

## Execução local

```bash
npm install
npm start
```

Depois, acesse `http://localhost:3000`.
